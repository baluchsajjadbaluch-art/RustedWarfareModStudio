# Rusted Warfare Ultimate Mod Studio 🛠️

استودیوی حرفه‌ای **آفلاین** اندروید برای ساخت و ویرایش مادهای بازی **Rusted Warfare** — ساخته‌شده با **Kotlin + Jetpack Compose**.

> ⚠️ صداقت کامل: سورس کامل و واقعی است؛ این ریپو **فایل APK آماده ندارد** مگر اینکه خودتان بیلد کنید یا فایل APK ضمیمه‌شده در ریلیزها را ببینید (ساختن APK به Android SDK نیاز دارد که در محیط ساخت این پروژه در دسترس نبود/محدود بود — روش بیلد دقیقاً پایین توضیح داده شده).

## 🔒 مدل امنیتی

- همه‌چیز از طریق **Storage Access Framework (SAF)** است — **هیچ مجوز ذخیره‌سازی** لازم نیست و برنامه کاملاً آفلاین است.
- هر تغییری در آرشیو اول در **فایل موقت** ساخته و CRC آن تأیید می‌شود، سپس **بکاپ** گرفته و فقط بعد از آن آرشیو اصلی بازنویسی می‌شود؛ در صورت خطا **بازگردانی خودکار** انجام می‌شود.
- محافظت از **zip-slip**: مسیرهای مخرب (`../`، مسیرهای ویندوزی، مسیر مطلق) رد می‌شوند.
- عملیات طولانی **قابل لغو** هستند و فضای کم دیسک به‌صورت ایمن عملیات را متوقف می‌کند.
- هرگز بدون تأیید شما فایل اصلی بازنویسی نمی‌شود.

## 🏗️ ساخت APK

### روش ۱ — Android Studio (ساده‌ترین)
1. این ریپو را Clone یا دانلود کنید.
2. در Android Studio: `File → Open` و پوشهٔ پروژه را باز کنید.
3. صبر کنید Gradle سینک شود (به اینترنت نیاز دارد).
4. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
5. APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

### روش ۲ — خط فرمان
```bash
# پیش‌نیاز: JDK 17+ و Android SDK (platform 34, build-tools 34.0.0)
git clone https://github.com/baluchsajjadbaluch-art/RustedWarfareModStudio.git
cd RustedWarfareModStudio
echo "sdk.dir=/path/to/your/android-sdk" > local.properties
./gradlew :app:assembleDebug          # APK دیباگ
./gradlew :app:assembleRelease        # APK ریلیز (R8 فعال)
./gradlew :app:testDebugUnitTest      # اجرای تست‌های واحد
```

**محدودیت شناخته‌شده:** فایل `gradlew` و `gradle-wrapper.jar` باید یک بار با `gradle wrapper --gradle-version 8.9` (یا از طریق Android Studio که خودش Wrapper را می‌سازد) تولید شود، چون این مخزن بدون باینری Wrapper منتشر شده است.

## 📲 نصب

1. APK را روی گوشی با **اندروید ۸.۰ به بالا** کپی کنید.
2. اجازهٔ «نصب از منابع ناشناس» را برای فایل‌منیجر بدهید.
3. APK را نصب کنید — هیچ مجوز مخربی درخواست نمی‌شود.

## 🚀 شروع سریع

1. از صفحهٔ اصلی **«باز کردن ZIP / RWMOD»** یا **«باز کردن پوشه ماد»** را بزنید.
2. ماد خود را از فایل‌منیجر انتخاب کنید (SAF).
3. برای ویرایش INI: روی فایل بزنید → ویرایشگر با هایلایت باز می‌شود → تغییر → **ذخیره** (ذخیره داخل آرشیو هم همان‌جا انجام می‌شود).
4. برای اعتبارسنجی: `ابزارها → اعتبارسنج ماد → اجرای بررسی`.
5. برای خروجی: `ابزارها → خروجی گرفتن`.

## 🧪 وضعیت تست‌ها

تست‌های واحد JVM برای بخش‌های خالص (پارسر INI، محافظت zip-slip) همراه پروژه است و با `./gradlew :app:testDebugUnitTest` اجرا می‌شود. تست روی دستگاه واقعی (بازکردن ماد واقعی شما، ذخیره، خروجی) باید توسط شما انجام شود — گزارش نقص‌ها را در Issues بنویسید.

## ⚠️ نکات صداقت

- **RWMOD**: بسته‌های ماد این بازی ZIP-سازگار هستند؛ برنامه با بررسی امضای `PK` صحت فرمت را تأیید می‌کند و فایلی که فقط پسوندش عوض شده و ZIP واقعی نیست را **قبول نمی‌کند**.
- قالب واحد نمونه و `mod_info.ini` بر پایهٔ **قراردادهای مستند جامعهٔ مادسازی** است؛ برای کلیدهای کامل به مستندات رسمی (انجمن Corroding Games) مراجعه کنید. اعتبارسنج کلیدهای ناشناخته را فقط «اطلاع» می‌دهد و چیزی را حذف نمی‌کند.
- تبدیل صدا فقط به **WAV/PCM16** انجام می‌شود (چون واقعاً با MediaCodec دیکد می‌شود)؛ ادعای تبدیل به OGG وجود ندارد.
- بکاپ‌ها در حافظهٔ `cache` برنامه نگه داشته می‌شوند (پاک‌شدنی با پاک‌کردن کش سیستم).
